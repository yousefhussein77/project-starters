# Store And Reuse

This file is the practical guide for saving this starter on your machine and reusing it later.

## After You Finish Preparing The Folder

1. Copy the whole `design_system/` folder to a safe location on your device.
2. Keep one master copy that you do not edit directly for client work.
3. For each new project, duplicate the master copy first.

Recommended local structure:

```text
D:\starter-kits\
  design_system\
  flask-app-starter\
  ui-snippets\
```

## Suggested Reuse Workflow

1. Duplicate the master `design_system/` folder.
2. Rename the duplicate if you want, for example:
   - `design_system_project_a`
   - `design_system_project_b`
3. Copy it into the new project.
4. Start by editing:
   - `themes/starter-theme.css`
   - `templates/navbar.html`
   - project logo assets
5. Keep generic files untouched unless the change is truly reusable.

## What To Customize First

- brand name
- colors
- logo
- layout direction if the project is RTL or LTR
- navigation links
- validation labels and messages if the project language changes

## Best Practice

When you improve a generic part:

- update your master saved copy too
- avoid mixing client-specific code back into the master starter

That keeps your local saved version clean and reusable.
